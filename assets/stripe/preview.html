FlowOS — Imagens dos Planos (Stripe)

Como usar no Stripe:

1. Abra cada SVG no browser, faça screenshot ou use Ctrl+P → Save as PDF
2. Converta para PNG (500×500) via squoosh.app ou cloudconvert.com
3. No Stripe Dashboard → Products → selecione o produto → Edit → faça upload da imagem

Tamanho recomendado: 500×500px PNG, fundo escuro já incluído.
