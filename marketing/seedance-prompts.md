# FlowOS — Prompts Seedance (CapCut Pro)

> Cole estes prompts diretamente no **Seedance** do CapCut Pro para gerar os vídeos de conteúdo do FlowOS.
> Seedance usa linguagem descritiva de cena — seja específico sobre movimento, câmera e duração.

---

## Como usar no CapCut Pro

1. Abra o CapCut Pro → **AI** → **Seedance**
2. Cole o prompt no campo de texto
3. Selecione duração: 5s ou 10s por cena
4. Estilo: **Cinematic** ou **Realistic**
5. Gere 2–3 variações, escolha a melhor
6. Monte as cenas no editor com corte rítmico

## DICAS DE PRODUÇÃO SEEDANCE

1. **Duração por cena:** use 5s para cortes rítmicos, 8–10s para slow reveals
2. **Estilo recomendado:** "Cinematic" para produto, "Realistic" para UGC
3. **Aspect ratio:** 9:16 para TikTok/Reels, 16:9 para YouTube, 1:1 para feed Instagram
4. **Negative prompt (o que evitar):** `people faces clearly visible, text overlay, watermark, distorted UI, unrealistic glow, cartoon style`
5. **Depois de gerar:** importe para o editor do CapCut → adicione música trending → exporte em 1080p
6. **TikTok primeiro:** sempre poste no TikTok antes → exporte sem watermark via CapCut → poste no Instagram Reels
