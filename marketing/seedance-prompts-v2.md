# FlowOS — Prompts Seedance 2.0 (即梦) — Versão Final

> Os prompts precisam estar em **chinês (中文)** para funcionar melhor no Seedance 2.0 do CapCut Pro.
> Cada bloco tem: **tradução em português** (para entender) + **prompt em chinês** (para copiar e colar).
> Faça upload dos screenshots do app como @图片1, @图片2 etc. antes de colar o prompt.

---

## Como preparar os frames antes de gerar

1. Capture os screenshots do app (ver guia em `seedance-frames-guide.md`)
2. No Seedance → **全能参考** (Modo Referência Completa)
3. Faça upload: @图片1 = Dashboard, @图片2 = Hábitos, @图片3 = Chat IA, @图片4 = Hábitos lista
4. Cole o prompt correspondente
5. Selecione duração e proporção indicados

## VÍDEO 1 — Life Score Pulsando

**Proporção**: 9:16 vertical | **Duração**: 8s | **Para**: TikTok / Instagram Reels

---

### O que este prompt faz (tradução):

> **@图片1 é o frame inicial.** A câmera foca no painel circular de pontuação de vida com fundo preto profundo. O anel tem gradiente azul de #3b82f6 até #06b6d4, com o número "73" pulsando no centro.
>
> **0–3s:** Plano extremamente fechado desliza lentamente para dentro do anel, partículas azuis se dispersam das bordas, o número tem animação de pulso fraco, o halo de luz se expande com o pulso.
>
> **4–6s:** Câmera recua lentamente, revelando cards flutuantes ao redor do anel — "Hábitos ✓", "Foco ●", "Finanças ↑" — cada card aparece em sequência com leve efeito de entrada elástica.
>
> **7–8s:** Câmera para. A interface inteira emana suave brilho azul neon. O número sobe levemente para "74", partículas flutuam para cima, tela funde para preto.
>
> **Estilo:** UI tech minimalista dark, cinematográfico, profundidade de campo rasa, brilho neon suave, sem nenhum texto ou marca d'água.

```

风格：极简主义深色科技UI，电影质感，浅景深，柔和霓虹发光，无任何文字水印。

## VÍDEO 2 — Dashboard Completo (Demo)

**Proporção**: 16:9 horizontal | **Duração**: 12s | **Para**: YouTube / LinkedIn

---

### O que este prompt faz (tradução):

> **@图片2 é o frame inicial.** Exibe a interface completa do painel dark, muito futurista, cores predominantes azul e ciano.
>
> **0–3s:** Abertura cinemática widescreen. A câmera desliza lentamente da esquerda, mostrando a barra de navegação lateral — ícones dos módulos acendem um a um, número "73" do Life Score flutua.
>
> **4–6s:** Câmera se move para o centro, foca na área de rastreamento de hábitos. Três animações de check-in de hábito se completam em sequência, check verde pisca, contador de streak pula.
>
> **7–9s:** Câmera continua para a direita, exibe gráfico de linha financeiro em tendência ascendente, dados do gráfico se atualizam dinamicamente, números sobem com efeito fluorescente.
>
> **10–12s:** Câmera recua para visão aérea completa. Todo o painel aparece inteiro, todos os módulos emitem suave pulsação azul simultânea, como um sistema que acabou de inicializar. Tela escurece.
>
> **Movimento:** Câmera lateral suave contínua, sem cortes, one-shot, com som de fundo tech.
> **Estilo:** Apresentação de produto SaaS premium, proporção 2.35:1, 24fps, preto profundo, paleta neon azul-ciano.
> **Proibido:** legendas, marca d'água, rostos reais.

### Prompt para copiar no Seedance:

```

## VÍDEO 3 — Chat IA Respondendo

**Proporção**: 9:16 vertical | **Duração**: 10s | **Para**: TikTok / Instagram Reels

---

### O que este prompt faz (tradução):

> **@图片3 é o frame inicial.** Mostra a interface de chat IA dark com bolhas de mensagem brilhando em azul.
>
> **0–2s:** Close-up de dedo digitando na tela, campo de texto recebe a pergunta: "Por que meu Life Score caiu essa semana?", cursor piscando, câmera em ângulo de 45°.
>
> **3–6s:** Após o envio, indicador de "IA pensando" aparece (três pontos azuis pulando), halo azul se expande da bolha para fora, criando sensação de processamento tech.
>
> **7–9s:** Resposta aparece palavra por palavra, conteúdo é análise personalizada: "Esta semana você completou apenas 2/5 hábitos diários, seu tempo de foco diminuiu 40% em relação à semana passada…" Texto azul aparece claro sobre fundo escuro.
>
> **10s:** Câmera recua lentamente, mostrando interface completa de conversa, com efeito sonoro tech de encerramento, tela escurece.
>
> **Destaque:** A resposta da IA deve parecer personalizada e orientada a dados, criando a sensação de "ela realmente me conhece".
> **Estilo:** Alta tecnologia, profundidade de campo rasa, tela do celular brilhando, fundo desfocado, iluminação cinemática.
> **Proibido:** legendas, marca d'água, rostos reais.

### Prompt para copiar no Seedance:

```
@图片3为首帧，展示深色AI对话界面，蓝色气泡发光。

0-2秒：特写手指在屏幕上打字，输入框中出现问题文字："为什么我这周的生命评分下降了？"，光标闪烁，镜头从侧面45度拍摄；
3-6秒：发送动画后，AI思考指示器出现（三个蓝点跳动），蓝色光晕从气泡位置向外扩散，营造AI正在处理的科技感；
7-9秒：回答文字逐字打印出现，内容为个性化分析："本周您只完成了2/5个日常习惯，专注时间比上周减少了40%……"，蓝色文字在深色背景上清晰呈现；
10秒：镜头缓缓拉远，显示完整对话界面，配合柔和科技收尾音效，画面渐暗。

重点：AI回答必须体现个性化、数据驱动的特征，营造"真正了解用户"的感觉。
风格：高端科技感，浅景深，手机屏幕发光，背景虚化，电影感光影。
禁止：字幕、水印、真实人脸。
```
